# Shaurma — магазин ресурсов для Тубитути

Витрина игрового магазина: валюта, ресурсы, наборы, бусты, премиум и сундуки.
Тёмная тема по умолчанию, светлая по переключателю, пять акцентных цветов, адаптивная вёрстка для телефона.

Стек: React 19, TypeScript, Vite, React Router, CSS Modules, Vitest, Oxlint.

Сайт: https://fgfjnker-collab.github.io/shaurma-client/

## Запуск

Нужен Node.js 20.19+ или 22+.

```bash
npm install
npm run dev        # http://localhost:5173
```

| Команда | Что делает |
| --- | --- |
| `npm run dev` | Dev-сервер с горячей перезагрузкой |
| `npm run build` | Продакшен-сборка в `dist/` (обычные URL: `/catalog`, `/product/…`) |
| `npm run build:static` | Сборка для статического хостинга (GitHub Pages и т. п.): URL вида `/#/catalog`, работает из любой папки |
| `npm run preview` | Посмотреть собранную версию |
| `npm test` | Юнит-тесты (корзина, каталог, форма заказа) |
| `npm run lint` | Линтер |
| `npm run typecheck` | Проверка типов |

При обычной сборке сервер должен отдавать `index.html` на все пути (на Vercel и Netlify это делается правилом rewrite).
Если такой настройки нет — используйте `build:static`.

## Публикация

Сайт раздаётся GitHub Pages из ветки `gh-pages`: в ней лежит только содержимое `dist/` после `npm run build:static`
(плюс пустой `.nojekyll`). Чтобы обновить сайт, пересоберите его и замените содержимое этой ветки.

## Страницы

- `/` — главная: первый экран, категории, хиты, акция, «как это работает», FAQ
- `/catalog` — каталог с поиском, категориями и сортировкой; фильтры хранятся в URL (`?category=bundles&q=…&sort=cheap`)
- `/product/:id` — карточка товара, похожие товары
- `/checkout` — оформление заказа: ник и ID игрока, почта, способ оплаты, промокод
- `/help` — инструкция, FAQ, контакты поддержки

Корзина открывается сбоку и сохраняется в `localStorage`, как и выбранная тема.

## Где что менять

| Что | Файл |
| --- | --- |
| Название магазина, игры, контакты поддержки | `src/config/site.ts` |
| Заголовок вкладки и описание для поисковиков | `index.html` |
| Товары (цены, скидки, бейджи, цвета плиток) | `src/data/products.ts` |
| Категории | `src/data/categories.ts` |
| Вопросы и ответы | `src/data/faq.ts` |
| Цвета тем и акцентов | `src/styles/tokens.css`, список акцентов — `src/context/themeContext.ts` |
| Заказы и промокоды | `src/api/orders.ts` |

Иконки товаров — из [Lucide](https://lucide.dev/icons/). Чтобы добавить новую, допишите её в `IconName` (`src/data/types.ts`) и в `src/components/Icon.tsx`.

## Бэкенд и оплата

Сейчас `src/api/orders.ts` — заглушка: заказ «создаётся» в браузере, промокод `SHAURMA10` проверяется там же,
а на странице оформления висит плашка «Демо-режим». Чтобы подключить сервер:

1. Замените тела `checkPromo` и `createOrder` на запросы к своему API.
2. Выставьте `IS_DEMO = false` — плашка и подсказка с промокодом пропадут.
3. Цены, скидки и промокоды обязательно пересчитывайте на сервере: всё, что лежит в клиенте, видно любому.

## Структура

```
src/
  api/          заглушка API заказов
  components/   шапка, подвал, корзина, карточка товара, переключатель темы…
  config/       настройки витрины
  context/      корзина и тема (React Context)
  data/         товары, категории, FAQ
  lib/          логика корзины, фильтров, валидации + тесты
  pages/        страницы
  styles/       токены цветов и базовые стили
```
